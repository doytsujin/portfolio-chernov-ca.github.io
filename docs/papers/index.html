Brain API: An Intent-Aware Control Plane for Policy-Governed Agentic Systems

arXiv preprint (cs.DC) Alexander Chernov · 2026

Proposes an intent-aware control plane whose central contribution is the decision artifact: a durable, versioned, auditable record of how an intent became an executable plan — which policies applied, which capabilities were evaluated, which alternatives were rejected, and why. A prototype of the decision layer agrees with the OPA Gatekeeper constraint library's published verdicts on 42 of 42 encodable cases; the context-signal and ranking stages remain design claims.

System One: a small trained model that judges dataset requests

Zenodo (report) Alexander Chernov · 2026

Reports a small model trained under Brain API to judge which capability of an Agentic Dataset a request is for, among the capabilities policy has already admitted; policy decides what may run, and every decision is recorded with the model's version. On generated dataset families never seen in training, the trained 1.5B model selects the right capability 98.1% of the time against 92.6% for the same base model prompted, and reaches 98.1% against 98.2% for a 7B reference at a fifth of its median latency. All 3,393 decision records re-derive from their recorded inputs to the same bytes.

Results note and carousel, Zenodo, 23 October 2026. DOI 10.5281/zenodo.23586630. CC BY 4.0.

A Policy Profile for Croissant: Refusal as a Property of the Dataset

arXiv preprint (cs.LG) Alexander Chernov · 2026

Supplies the half of Croissant's data use conditions that no version specifies — how they are evaluated: an additive profile lets a dataset declare the operations it admits and the conditions under which it admits them, over five operators with a complete decision procedure, so a gate decides from the descriptor alone and records what it checked. On descriptors that gated a real nf-core pipeline, profile decisions match the native record for record at 11.7 µs added cost against a 119 µs decision.

arXiv:2609.19640 [cs.LG], v1, 17 September 2026. DOI 10.48550/arXiv.2609.19640.
